# Рыбный Прогноз

Лендинг и интерактивное демо для трёх водоёмов Нижегородской области. Прогноз, погода и рекомендации в демо заданы заранее. Внешние API и регистрация не используются.

Для локального просмотра выполните:

```sh
python -m http.server 3000 --directory dist
```

Откройте http://localhost:3000. Сборка и установка зависимостей не требуются. Текущая страница находится в `dist/index.html`, стили — в `dist/assets/landing.css`, сценарии — в `dist/assets/forecast.js`.

`copy_site.py`, `update_landing.py` и `source/partners.html` относятся к предыдущему лендингу. Повторное копирование через `copy_site.py` перезапишет текущую страницу.
