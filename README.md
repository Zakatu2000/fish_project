# Рыбный Прогноз

Лендинг учебного проекта для рыбаков: прогноз клёва, рекомендации по снастям и планируемые рекламные размещения магазинов и платных водоёмов.

## Публикация

GitHub Pages публикует ветку `main`, папку `/docs`. Файлы подготовлены для пути `/fish_project/`, включая клиентский роутер, изображения и локальные шрифты. Сборка на стороне хостинга не нужна.

## Изменение сайта

- `dist/` — версия сайта для корня домена.
- `source/partners.html` — редактируемый раздел для рекламодателей.
- `update_landing.py` — применяет изменения к HTML и клиентскому модулю, удаляет бейдж исходной платформы.
- `build_pages.py` — создаёт версию для GitHub Pages в `docs/` и проверяет пути ресурсов.
- `docs/` — готовая опубликованная версия.
- `Сравнение_и_план_доработок.md` — сравнение с рабочей тетрадью и приоритеты развития.

После редактирования раздела партнёров:

```sh
python update_landing.py
python build_pages.py
git add .
git commit -m "Update landing content"
git push
```

После обновления `docs/` в `main` GitHub Pages автоматически публикует изменения.

## Локальный просмотр

```sh
python -m http.server 3000 --directory dist
```

Откройте http://localhost:3000. Для локального просмотра используйте `dist/`; версия в `docs/` подготовлена для публичного пути `/fish_project/`.

## Текущий этап

Сайт представляет идею MVP. Показанный прогноз 78% — демонстрационный пример. Рабочий расчёт, регистрация, приём заявок и действующие рекламные предложения ещё не реализованы. Кнопки ведут к разделу `#signup`, где пока расположен призыв к действию.

Исходная публичная версия: https://project-42307b.lovable.app/. Бейдж и аналитика исходной платформы удалены. Скрипт `copy_site.py` позволяет повторно скачать публичную версию и применить текущие изменения; для этого нужны Python 3 и curl. После него запустите `python build_pages.py`.
